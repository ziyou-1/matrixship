# 同款替换重生成、动态时长、视频预览与素材绑定设计

## 背景

当前漫剧项目模式存在四个相关问题：

1. 首帧、尾帧和视频重生成入口在页面忙碌时静默返回，且点击入口没有结构化日志，用户无法判断按钮是否生效。
2. 项目配置固定使用约 5 秒视频时长。项目 303 的三个 Vidu 片段实际均为 4.04 秒，但口播稿预计需要约 12.7、7.5、8.3 秒。
3. 视频列只提供表格内播放和全屏模式，没有与图片列一致的独立预览窗口。
4. 画面描述过滤不完整，把原片总结、车型、展厅和整张关键帧表传给漫剧生成器，削弱了上传人物、场景和道具的优先级。

## 目标

- 重生成按钮点击后必须立即显示状态，并记录可脱敏追踪的结构化日志。
- 根据最终口播稿估算自然口播时长，单段口播最长 15 秒；超过后按语义拆成连续片段。
- 视频列点击后打开非全屏、可缩放的独立播放窗口。
- 首尾帧和视频生成必须显式绑定上传的人物、场景和道具，原片仅提供动作、站位、运镜和节奏。

## 非目标

- 不修改已完成的旧任务 JSON。
- 不自动重启本地客户端。
- 不修改中心服鉴权、计费或 003/Test003 账号策略。
- 不重新实现漫剧生成器已有的模型时长适配和素材解析能力。

## 方案

### 1. 重生成交互与可观测性

- 首帧、尾帧和视频按钮使用稳定的片段对象或片段索引，不依赖表格当前选中状态。
- 点击入口先记录 JSON 日志，字段只包含任务 ID、漫剧项目 ID、片段序号、重生成类型和当前忙碌状态。
- 页面忙碌时不再静默返回，状态栏显示“当前任务正在处理，请稍候后重试”。
- 接受操作后立即显示“正在提交首帧/尾帧/视频重生成”，后台阶段继续更新状态。
- 成功和失败都必须解除忙碌状态、刷新表格；失败保留错误编号，不记录令牌或完整受保护媒体 URL。

### 2. 口播时长和自动拆分

- 使用现有中文口播估算函数，按有效字符、标点停顿计算自然口播时长。
- 在创建漫剧项目前，以用户最终编辑后的口播稿重新计算每段 `speechDurationSec`。
- 单段预计时长大于 15 秒时，优先在句号、问号、感叹号、分号和逗号处分割，按预计时长尽量均衡拆成两个连续片段；若子片段仍超过 15 秒则继续拆分。
- 新片段继承人物、场景、道具和原片动作上下文，并增加“承接上一片段”的连续性约束；重新编号并压紧时间轴。
- 请求视频时发送每个分镜的目标时长。目标时长向上匹配当前模型支持档位；Vidu 的 15 秒口播使用 16 秒视频档位，预留自然收尾，不截断台词。
- 自动模式仍保留模型生成视频自带声音，不生成 TTS，不替换音轨。

### 3. 视频弹窗预览

- 新增独立的 `ComicVideoPreviewDialog`，只加载已下载并通过媒体校验的本地视频。
- 点击视频画面或预览按钮打开弹窗；表格内播放按钮继续保留。
- 弹窗默认不全屏，最大尺寸不超过可用屏幕的 82%，保持视频宽高比。
- 弹窗包含播放/暂停、进度、音量和关闭控制；关闭时释放播放器资源并恢复表格播放器状态。
- 删除现有“全屏”行为，避免把表格播放器控件搬移到全屏窗口。

### 4. 漫剧剧本与素材绑定

- 画面描述改为短结构：素材绑定、原片动作/站位、镜头/节奏、连续性要求。
- 当上传了对应素材时，移除原片人物外观、产品名称、场景名称、字幕、OCR、口播转写、全局总结和关键帧表。
- 素材绑定写明：角色使用项目库“主角”参考图，场景使用“场景1”参考图，道具使用“道具1”参考图；文字与参考图冲突时以参考图为准。
- 除现有角色、场景、道具 ID 外，首尾帧和视频请求显式携带分类参考图字段：角色参考图、场景参考图、道具参考图。
- 口播稿只进入对白字段，不再混入画面描述；自动声音模式把口播稿作为模型对白要求，但不触发 TTS。

## 数据流

1. 用户编辑最终口播稿。
2. 点击开始生成时同步表格内容并执行时长规划。
3. 超过 15 秒的口播拆成连续片段，生成稳定序号和目标时长。
4. 上传人物、场景和道具，写入漫剧项目库。
5. 创建/更新分镜时写入精简画面描述、最终对白、素材 ID 和分类参考图。
6. 按目标时长生成首尾帧和视频。
7. 下载本地后校验视频、音轨和实际时长，页面显示本地预览。

## 错误处理

- 时长规划失败：生成前阻断，提示对应片段，不产生远程费用。
- 拆分后无有效文本：保留原片段并记录结构化告警。
- 素材绑定缺失：生成前阻断并指出角色、场景或道具缺失项。
- 重生成提交失败：保留旧首尾帧或旧视频，记录错误编号并允许再次重试。
- 预览加载失败：不打开外部公网链接，显示本地媒体错误编号。

## 测试策略

- 单元测试：口播估时、15 秒边界、递归拆分、标点优先和连续性字段。
- 契约测试：项目创建和分镜更新请求包含目标时长、分类素材 ID/URL，画面描述不含原片车型、展厅、OCR 和全局总结。
- UI 测试：三个重生成按钮均触发正确片段；忙碌状态有提示；视频点击打开非全屏弹窗并释放播放器。
- 回归测试：自动声音模式不出现 TTS/audio prompt；旧任务仍能打开；图片弹窗行为不变。
- 冒烟测试：使用假适配器跑通“编辑口播 -> 拆分 -> 创建项目 -> 写入素材 -> 生成首尾帧 -> 生成视频 -> 本地预览”。

## 回滚

- 修改集中在本地客户端的时长规划、漫剧载荷构造和预览组件。
- 发布前保留当前 `matrix_native_client.py` 文件备份或稳定 Git 引用。
- 若新任务失败率超过 1%，回滚本地客户端版本；远程漫剧服务无需回滚，因为本方案不要求修改远程接口。

## 验收标准

- 点击三个重生成入口均在 1 秒内显示可见状态。
- 预计口播不超过 15 秒；超长稿自动拆分且无文本丢失。
- 项目 303 同等输入下，第 1 段不再按 4 秒请求，而是使用能容纳约 12.7 秒口播的时长档位。
- 视频预览为独立窗口且不是全屏。
- 发送给漫剧生成器的画面描述明确引用上传素材，不再包含原片车型/展厅和全局关键帧表。
