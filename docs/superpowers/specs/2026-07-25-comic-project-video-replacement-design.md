# 同款替换漫剧项目模式设计

## 目标

将新的“同款替换”任务从现有 LK888 单段视频编辑链路，切换为自动调用漫剧生成器后端接口的“漫剧项目模式”。用户仍在本地客户端上传人物图、产品图、场景图并编辑口播稿；本地客户端把这些输入映射为漫剧项目的人物、道具、场景和分镜，按片段生成流程图与视频，最终用每个片段当前最新视频合成完整成片。

旧任务必须继续按旧 JSON 打开和查看，不做强制迁移。

## 用户范围

- 新建同款替换任务默认走漫剧项目模式。
- 旧同款替换任务继续保留原表格、原状态、原生成结果查看能力。
- 页面保留上传产品图、人物图、场景图和口播稿编辑。
- 产品图在漫剧生成器中统一映射为“道具”。
- 片段区域在漫剧项目模式下显示：序号、口播稿、流程图生成、视频、单段重新生成。
- 不自动重启本地客户端。

## 非功能性需求

| 项目 | 要求 |
| --- | --- |
| 可观测 | 每个任务保存漫剧项目 ID、任务 ID、分镜 ID、模型、阶段、耗时、错误编号和脱敏错误上下文。 |
| 可回滚 | 通过任务字段隔离新旧模式；旧任务不迁移；必要时通过环境开关回退到旧同款替换链路。 |
| 可追溯 | 本地任务 JSON 记录本地片段、漫剧项目、分镜和最终视频之间的映射。 |
| 延迟 | 单片段生成采用远程异步轮询；页面每秒刷新已用时和当前阶段。 |
| 并发 | 首版采用可配置的小并发生成片段，默认 2 路，避免远程接口限流和本地状态竞争。 |
| 显存 | 本地不新增深度学习模型，GPU 显存增量为 0 MiB。 |
| 隐私 | 日志不记录 token、签名 URL 查询串、完整人物图内容或完整远程响应。 |
| 兼容 | 老 JSON 没有 `replacementMode="comic_project"` 时仍按旧链路渲染。 |

## 方案对比

| 方案 | 描述 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- | --- |
| A. 本地客户端直连漫剧 API | 本地客户端调用 `http://120.26.194.174/api/v1/comic-drama/*`。 | 改动集中，能快速接入，片段状态可控。 | 需要确认当前本地登录 token 是否可被漫剧 API 接受。 | 采用。 |
| B. 调用漫剧 Agent 一键生成 | 只调用 `/agent/generate` 类接口。 | 接入短。 | 片段重生、流程图列、视频列和错误追踪不可控。 | 不采用。 |
| C. 中心服做代理 | 中心服统一转发或换取漫剧凭证。 | 安全边界更清晰，线上更标准。 | 改中心服，需中心服重启，范围更大。 | 后续可升级。 |

## 架构

新模式在 `backend/matrix_native_client.py` 内新增一层漫剧项目适配器，首版不重构整页。适配器只负责接口调用、任务轮询、字段映射和错误脱敏；页面继续负责收集上传素材、编辑口播稿、展示片段和最终合成。

任务 JSON 通过 `replacementMode` 区分：

```json
{
  "replacementMode": "comic_project",
  "comicProjectId": "",
  "comicProjectUrl": "",
  "comicConfig": {
    "storyboardWorkflowMode": "action_flow",
    "videoModel": "",
    "imageModel": "",
    "audioMode": "tts"
  },
  "comicAssets": {
    "characters": [],
    "scenes": [],
    "props": []
  },
  "segments": []
}
```

没有该字段，或字段不是 `comic_project` 的旧任务，继续走现有逻辑。

## 数据流

1. 本地客户端接收分解视频结果，读取每个片段的原始提示词、时间、口播稿和画面描述。
2. 用户上传人物图、场景图、产品图；本地上传为公网可访问素材 URL。
3. 本地创建漫剧项目，`source_text` 使用片段口播稿和分镜描述拼成剧本。
4. 本地把人物图写入漫剧项目人物库，场景图写入场景库，产品图写入道具库。
5. 本地为每个片段创建或更新漫剧分镜，分镜口播稿以用户最终编辑内容为准。
6. 调用流程图生成接口，结果写回片段的 `flowchartUrl` / `flowchartTaskId`。
7. 调用视频生成接口，传入人物、场景、道具、流程图和口播稿，结果写回片段的 `videoUrl` / `videoPath`。
8. 用户单段重生时，只重新生成该片段流程图和视频，成功后覆盖该片段当前视频。
9. 最终合成使用所有当前最新片段视频，生成完整成片并入库。

## 声音链路

声音必须和字幕、口型保持同一来源。

| 声音来源 | 规则 |
| --- | --- |
| AI 音色配音 | 每段口播稿作为对白文本传给漫剧项目；视频生成必须以该文本生成声音、字幕和口型。 |
| 上传完整配音 | 用户上传的是完整成片配音；首版需要拆分或映射到片段对白音频后再传给漫剧分镜，不能只在最终合成时覆盖音轨。若漫剧接口暂不支持片段对白音频，页面必须提示“上传完整配音暂不能保证口型同步”，并阻止选择该模式生成。 |
| 原片声音 | 不允许修改口播稿内容；如果用户改了口播稿，必须切换到 AI 音色配音或上传完整配音，否则声音、字幕、口型无法一致。 |

首版推荐先完整打通 AI 音色配音。上传完整配音只有在确认漫剧后端存在片段音频字段或上传接口后再放开。

## 页面行为

新模式片段表只保留业务需要的列：

- 序号
- 口播稿
- 流程图生成
- 视频
- 操作

流程图列显示生成状态、缩略图或错误编号。视频列显示生成状态、缩略图或本地文件名。操作列提供单段重新生成。删除片段后必须重新压紧待生成片段的序号和最终合成顺序。

页面进度需要显示更细阶段：

- 上传素材
- 创建漫剧项目
- 写入人物/场景/道具
- 写入分镜
- 片段 N 流程图生成
- 片段 N 视频生成
- 下载片段视频
- 合成完整视频

已用时需要按秒刷新，不能只在阶段结束后更新。

## 错误处理

所有远程异常统一转换为本地错误编号，并保存脱敏上下文：

```json
{
  "errorId": "err-...",
  "stage": "comic_generate_video",
  "comicProjectId": "...",
  "storyboardId": "...",
  "taskId": "...",
  "statusCode": 400,
  "message": "参数验证失败"
}
```

错误日志必须不包含 token、签名 URL 查询串、完整远程响应中的敏感素材地址。

## 回滚

- 新任务默认 `replacementMode="comic_project"`。
- 旧任务没有该字段，不受影响。
- 增加环境开关 `VIDEO_REPLACE_DEFAULT_MODE`：
  - `comic_project`：新任务走漫剧项目模式。
  - `legacy`：新任务回到旧同款替换链路。
- 不删除旧链路代码，直到漫剧项目模式稳定上线后再单独清理。

## Phase 0 冒烟测试

实现生产代码前先做最小接口冒烟：

1. 使用一段假剧本和 1 张人物图、1 张场景图、1 张道具图创建漫剧项目。
2. 创建或更新 1 个分镜。
3. 生成 1 张流程图。
4. 生成 1 个短视频片段。
5. 下载结果视频，确认不是空文件。
6. 把失败点写入 `docs/TROUBLESHOOTING.md`。

如果认证失败，停止实现主链路，先确认本地客户端 token 是否可直连漫剧 API，或改走中心服代理方案。

## 测试策略

- 单元测试：素材映射、剧本拼装、任务 JSON 兼容、新旧模式判定、错误脱敏。
- 冒烟测试：最小漫剧项目创建、分镜生成、流程图生成、视频生成。
- UI 回归：旧任务打开不变，新任务片段表列变为漫剧项目模式列。
- 合成验证：单段重生后最终合成使用最新片段视频。
