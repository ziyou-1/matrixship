# 同款替换单人物与自动时长设计

## 目标

新建漫剧项目模式同款替换任务只接收一张清晰正脸全身人物图，只创建一个主角。用户修改后的完整口播稿和所选音色直接传给漫剧生成器，不再由本地客户端提前生成配音或测量音频时长；当台词超过原片片段时长时，允许漫剧生成器自动延长片段，确保台词完整。

## 行为

- 人物选择框只允许选择一张图片，页面文案改为“上传主角正脸全身照”。
- 新任务只保存一个人物路径和一个人物公网 URL。
- 兼容旧任务：读取旧的 `personReferencePaths` / `personReferenceUrls` 数组时只使用第一项，不迁移或删除旧任务 JSON。
- 漫剧项目只创建一个名为“主角”的角色，人物图和用户选择的 AI 音色都绑定到该角色。
- 分镜更新继续传递用户最终口播稿、主角、场景和道具绑定。
- 本地流程删除 `prepare-dialogue-audio` 调用，不生成预配音、不测量时长、不覆盖片段 `duration`。
- 流程图和视频生成请求都携带完整 `dialogue.text` 和 `dialogue.voice`，并设置自动匹配音频时长。
- 漫剧生成器可以根据完整台词延长片段，不截断台词。
