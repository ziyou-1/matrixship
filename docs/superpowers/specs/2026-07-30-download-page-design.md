# 云灵星图 AI 爆款复刻平台下载页设计

## 1. 背景

当前项目是以 PySide6 原生 Windows 客户端为主的正式软件，中心服已经提供安装包直链能力，但尚未提供面向客户的公开下载页。用户希望先设计并写好公网客户下载页面，暂时不把下载按钮接到真实安装包。

下载页面向首次接触产品的客户、企业使用者和交付人员，主要目标是清楚说明这是什么软件、由哪个公司提供、适用于什么系统，以及后续如何获取 Windows 客户端。

## 2. 已确认决策

- 页面类型：公网客户下载页。
- 首屏主标题：`云灵星图 AI 爆款复刻平台 Windows 客户端下载`。
- 公司名称：`云灵星图数字科技有限公司`。
- 视觉风格：深色科技商务。
- 下载按钮状态：禁用状态，暂不链接真实安装包。
- 下载按钮文案：`Windows 客户端即将开放下载`。
- 按钮下方说明：`正式安装包发布后，将由云灵星图数字科技有限公司提供下载。`
- 推荐公开路径：`/download`。

## 3. 非目标

- 本阶段不接 `/MatrixShipAgent-Setup.exe`。
- 本阶段不改变现有安装包下载接口。
- 本阶段不新增登录、注册、支付、工单或后台管理能力。
- 本阶段不新增独立前端项目。
- 本阶段不暴露任何 API Key、Token、数据库地址、平台账号授权信息或内部部署路径。

## 4. 页面信息架构

### 4.1 首屏

首屏直接表达下载页目的，不做营销式空泛介绍。

内容包括：

- 产品标题：`云灵星图 AI 爆款复刻平台 Windows 客户端下载`
- 副标题：`面向短视频内容团队的本地执行客户端，支持爆款采集、视频拆解、同款生成、素材管理与账号矩阵协作。`
- 主按钮：`Windows 客户端即将开放下载`
- 按钮状态：禁用，不可点击，不带真实下载链接。
- 辅助信息：`Windows 10/11`、`最新版即将发布`、`云灵星图数字科技有限公司出品`。
- 视觉元素：品牌图标、产品能力面板、状态徽标，不使用空泛插画。

首屏底部需要露出下一段“核心能力”，避免页面停留在单屏广告感。

### 4.2 核心能力

展示 4 个能力模块：

- 爆款采集：采集抖音、小红书公开内容，沉淀为参考素材。
- 视频拆解：提取结构、口播、画面节奏和关键帧。
- 同款复刻：基于产品、人物、场景生成可审核的新素材。
- 账号矩阵协作：支持多账号、任务中心、素材与发布协同。

### 4.3 安装步骤

展示 4 步流程，桌面端横向，移动端纵向：

1. 等待正式安装包开放。
2. 获取 Windows 客户端安装包。
3. 运行安装程序并登录企业账号。
4. 进入客户端开始采集、拆解和生成。

由于本阶段按钮不接下载，第一步文案必须避免暗示用户现在就能下载。

### 4.4 安全与支持

展示客户关心的正式交付信息：

- 安装包来源：云灵星图数字科技有限公司。
- 下载状态：Windows 客户端即将开放下载。
- 更新机制：客户端启动后会自动检查新版本。
- 数据说明：平台账号授权、素材、日志按项目配置保存，下载页不展示敏感信息。
- 下载失败或未开放时：联系管理员或实施人员获取最新交付安排。

## 5. 视觉设计

采用深色科技商务风：

- 背景：深灰黑为主，使用克制的线性层次、网格感或微弱发光边界。
- 主色：延续现有客户端蓝紫强调色，避免大面积单一紫蓝渐变。
- 信息密度：首屏清晰直接，下方内容紧凑但可扫描。
- 卡片：仅用于能力模块和状态信息，不做多层嵌套卡片。
- 字体层级：首屏标题可以大，但能力卡片和步骤区使用克制字号。
- 响应式：桌面端两栏布局，移动端单栏堆叠，按钮和状态信息不可溢出。
- 可访问性：禁用按钮需要有明显禁用态，文字对比度足够，焦点样式清晰。

## 6. 技术方案建议

### 6.1 推荐实现

使用中心服内置 HTML 字符串提供 `/download` 页面。

理由：

- 当前项目没有独立前端站点，中心服内置页面改动最小。
- 当前测试明确约束不要恢复旧的产品网页目录，内置页面更符合现有架构。
- 部署只依赖中心服更新，不需要额外构建前端产物。
- 回滚只需要删除 `/download` 路由和页面渲染函数。

### 6.2 暂不采用的方案

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 新增独立 `download.html` | 文件清晰，易独立编辑 | 与当前“无产品 HTML 页面”的约束冲突，需要调整测试和部署边界 | 暂不采用 |
| 新增完整前端项目 | 扩展能力强 | 对单页下载页过重，增加构建和部署复杂度 | 不采用 |
| 复用安装包直链页 | 改动最小 | 不能体现产品和公司信任信息 | 不采用 |

## 7. 可观测、可回滚、可追溯

- 可观测：页面访问可以通过中心服已有访问日志和反向代理日志观察；若后续增加页面异常记录，日志必须结构化且脱敏。
- 可回滚：删除 `/download` 路由和 HTML 渲染函数即可回滚；现有安装包直链不受影响。
- 可追溯：实现时同步更新 `CHANGELOG.md`、相关文档和 `docs/IMPLEMENTATION.md` 行号引用。

## 8. 测试策略

实现阶段应补充自动化测试：

- `/download` 返回 HTTP 200。
- 响应 `Content-Type` 为 `text/html; charset=utf-8`。
- 页面包含主标题 `云灵星图 AI 爆款复刻平台 Windows 客户端下载`。
- 页面包含禁用按钮文案 `Windows 客户端即将开放下载`。
- 页面不包含 `/MatrixShipAgent-Setup.exe` 链接。
- 现有 `/MatrixShipAgent-Setup.exe` 行为保持不变。

实现后应做冒烟验证：

- 本地启动中心服。
- 访问 `/download`。
- 验证桌面宽度和移动宽度下内容不重叠、不溢出。
- 验证禁用按钮不可点击且没有真实下载链接。

## 9. 验收标准

- 客户打开 `/download` 后第一眼能看到产品名称、Windows 客户端定位和公司背书。
- 页面视觉符合深色科技商务风，不像临时测试页。
- 下载按钮处于禁用状态，不跳转、不下载、不暴露安装包路径。
- 页面说明清楚表达“即将开放下载”。
- 页面不引入硬编码密钥、数据库连接串或内部敏感路径。
- 页面在桌面和移动端都可读，主要文字不溢出、不重叠。
- 回滚不影响现有客户端更新检查和安装包直链接口。
